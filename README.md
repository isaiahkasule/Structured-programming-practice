# Structured-programming-practice

This contains eight C programs demonstrating core structured programming concepts like output, input/decisions/loops, for CSC1101, UCU.



\## Exercise 1 – Basic Output

Source: Deitel \& Deitel, C How to Program, 9th Edition, Chapter 2, Exercise 2.9(a).

What the program does: The program prints out a fixed decorative bordered box using extended ASCII characters.

Concepts used: printf statements(printf(“”);, escape sequences (\\xNN hex character codes) and string literals

How it works: row 1 has a left top corner followed by horizontal lines and then a top right corner. rows 2 to 5 have vertical lines at the end with the shaded texture in between. row 6 has a bottom left corner followed by horizintal lines and finally a bottom right corner
